## Projects

**[OneHelper](https://github.com/sudarsan017/OneHelper)** — Java, JSON, CLI

Local environment setup was a 20–30 minute manual process — commenting beans, modifying config files, adjusting DB values, configuring Maven, JUnit, and two Tomcat instances. One missed value meant cascading port-conflict exceptions with no recovery path. I faced friction with it when I was new to my project. Seniors got the muscle memory and other workarounds. I built the fix myself.

I built a JSON-driven engine that handles all of it. Line-level and file-level change application. Automatic port-conflict resolution. Maven, JUnit, and Tomcat provisioning. Git patch application baked into the Java process via ProcessBuilder. One bat-file click. Under 2 seconds.

**[RAG Chat Explorer](https://github.com/sudarsan017/rag-chat-explorer)**

An exploratory build to understand how RAG pipelines actually work. Scrapes data, stores it in a vector database, and answers questions grounded in that data. No hallucinations from general knowledge — answers come only from what's in the DB. Built it to understand the retrieval-augmented generation pipeline end to end, not to ship it.
